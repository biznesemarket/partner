# Глоссарий проекта «Партнер»

| Поле | Значение |
|---|---|
| Версия | 1.1 |
| Дата | 2026-11-13 |
| Назначение | Единый словарь терминов для документации, кода и валидатора |

## 1. Продукт и стороны

| Термин | Обозначение | Значение |
|---|---|---|
| Партнер | Partner | Продукт: учет времени работы с ИИ-агентом и начисление долей |
| Организация | tenant | Клиент продукта; изолированные данные, политика и участники |
| Проект | project | Репозиторий (или его часть) в рамках организации, со своей политикой |
| Директор | director | Роль: утверждает политику, корректирует дни, решает о переоценке |
| Участник | participant | Человек, чья работа учитывается и конвертируется во вклад |
| Разработчик | developer | Участник, работающий с ИИ-агентом над кодом |
| Юрист | lawyer | Роль: снимает юридические гейты до включения модуля 06-legal |
| Хранитель | maintainer | Роль: принимает PR, ведет реестр и снапшоты |

## 2. Время и сессии

| Термин | Обозначение | Значение |
|---|---|---|
| Сессия | session | Непрерывный отрезок работы человека с агентом над задачей |
| Heartbeat | heartbeat | Событие активности, отправляемое агент-китом раз в 30 с |
| Активное время | active_human | Класс: человек подает сигналы работы (ввод, навигация) |
| Супервизия | supervised_agent | Класс: агент работает, человек присутствует и подтверждает |
| Автономное время | autonomous_agent | Класс: агент работает без человека; коэффициент `k_autonomous` |
| Простой | idle | Нет сигналов дольше порога; не оплачивается |
| Оплачиваемые часы | paid_hours | Часы после коэффициентов и капов (см. time-accounting §4) |
| Кап дня | daily_cap_hours | Максимум оплачиваемых часов в сутки; задает директор |
| Кап автономного класса | autonomous_paid_cap_hours | Максимум оплач. часов автономного класса в сутки |
| Окно присутствия | presence_window_sec | Интервал, в котором сигнал человека считается присутствием |
| Расхождение часов | clock_skew | Отклонение часов клиента от серверных сверх порога |

## 3. Деньги и доли

| Термин | Обозначение | Значение |
|---|---|---|
| Ставка часа | rate_rub_per_hour | Стоимость 1 оплачиваемого часа; версионируется (дефолт 500 ₽) |
| Оценка проекта | valuation_rub | Стоимость 100% проекта; версионируется (дефолт 10 000 000 ₽) |
| Вклад-рубли | V_person | Накопленные рубли вклада участника; учетная единица, не деньги на руки |
| Доля | share_display | Процент проекта = V_person / valuation × 100; расчетная величина |
| Пул | pool_pct | Доля проекта, распределаемая по вкладам (дефолт 30%) |
| Пол основателя | founder_floor_pct | Минимальная доля директора при расчете (дефолт 70%) |
| Фантомная доля | phantom share | Расчетная доля без изменения УК; юридически фиксируется по снапшоту |
| Вестинг | vesting | Постепенное закрепление доли по активным месяцам (48 / клифф 12) |
| Активный месяц | active month | Месяц с ≥ 20 оплачиваемых часов (или ≥ 10 000 ₽ при fixed_price) |
| Клифф | cliff_months | Срок, до которого вестинг не начинается (12 месяцев) |
| Pending | pending | Режим: рубли копятся, доля не растет (пул исчерпан или переоценка) |
| Денежная часть | cash_share_pct | Доля начисления живыми деньгами; уменьшает вклад-рубли |
| Переоценка | revaluation | Смена оценки проекта; меняет отображаемую долю всех пропорционально |

## 4. Процесс и расчет

| Термин | Обозначение | Значение |
|---|---|---|
| Закрытие дня | day_close | Автоматический расчет в 00:00 пояса проекта (дефолт Europe/Moscow) |
| Дайджест | digest | Утреннее сообщение: часы, ₽ и % за день и накопленно, капы, флаги |
| Раскладка | explain | Разбор расчета дня по интервалам, классам, коэффициентам |
| Снапшот | snapshot | Месячный итог в git с SHA-256 входных данных; юридический якорь |
| Компенсирующая запись | adjustment | Новая запись, исправляющая закрытый день; исходная не меняется |
| Окно спора | dispute_window_days | Срок оспаривания дня (дефолт 3 суток с закрытия) |
| Заднее число | backdating | Изменение правил для прошлых дней; запрещено (V-04) |
| Флаг дня | day flag | Метка аномалии (no_output, replay, cap_applied и др.) |
| Якорь в git | git anchor | Фиксация дневных/месячных итогов коммитом для доказательной базы |
| Режим учета | mode | time_based (основной), fixed_price (опция), hybrid |
| Repo-pack | repo-pack | Пакет, ставящийся в репозиторий клиента: AGENTS.block, policy, workflows |
