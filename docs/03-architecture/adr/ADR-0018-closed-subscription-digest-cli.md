# ADR-0018: Закрытая подписка; витрина — дайджест и CLI

| Поле | Значение |
|---|---|
| Статус | Принято |
| Дата | 2026-11-13 |
| Решающий | Основатель |
| Заменяет | ADR-0002 (лицензия), ADR-0015 (витрина) |

## Решение

1. **Модель поставки — закрытая подписка self-hosted.** Исходный код
   не публикуется; клиент получает образы/пакеты и лицензионный ключ.
   Лицензия проприетарная, «все права защищены».
2. **Витрина MVP — утренний дайджест + CLI.** Веб-дашборд в MVP не входит.
   Директор и участник получают: дайджест (IDE/агент/почта/мессенджер),
   CLI-отчеты, месячные снапшоты.
3. **Дашборд — предмет отдельного решения** при появлении платящих клиентов
   с запросом на интерактив (переоценка ADR-0015 сохраняется как триггер).
4. **Публичный сайт продукта** — маркетинговый и документационный,
   без данных клиентов и без реальных цифр участников.

## Альтернативы

Open-core — отклонено (размывает ценность подписки). SaaS-мультиарендность
в нашем облаке — отложено (клиенты хотят код и данные у себя).
Дашборд в MVP — отклонено (расходы и поверхность атаки без спроса).

## Последствия

Плюсы: понятная монетизация, минимум сервисов, меньше рисков утечки.
Минусы: нужен механизм лицензирования и обновлений; часть клиентов
будет просить UI — компенсируется качественным дайджестом и CLI.
