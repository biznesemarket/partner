## Зачем ADR

ADR фиксирует решения, которые нельзя менять молча. Изменение правил
расчета, лицензии или хранилища без ADR запрещено (AGENTS.md §2).

## Полные тексты ADR

Полные тексты ADR-0016…0018 — в соседних файлах этого каталога.
ADR-0019 (ежедневное начисление, активный месяц = ≥ 20 оплачиваемых часов,
pending при исчерпании пула) зафиксирован текстом в `02-policy/equity-model.md`
и `02-policy/versioning.md`; при переносе в полноценный ADR-каталог
неразрывно связан с ними.

### ADR-0019 · Содержание решения (сводка)

1. Активный месяц = месяц с ≥ `active_month_min_paid_hours` (дефолт 20)
   оплачиваемых часов. При ставке 500 ₽/ч это эквивалент прежнего порога
   10 000 ₽, поэтому юридические шаблоны C4/C6 остаются валидными.
2. Вестинг сохраняется в активных месяцах (48 / клифф 12).
3. Накопленные рубли неизменны; доля отображается от текущей оценки.
4. При исчерпании пула — режим pending: учет продолжается, рубли копятся,
   доля не растет до решения директора.

## Жизненный цикл ADR

Предложение → обсуждение в issue → Принято/Отклонено (решающий — директор
проекта) → номер закреплен навсегда. Отмена решения = новый ADR со статусом
«Заменено ADR-xxxx», старый не удаляется.
