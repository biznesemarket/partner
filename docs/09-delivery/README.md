# Пакет инструкций для поставки

Готовые документы для передачи клиенту и вендорской команде. Источник
истины — markdown-документы из `docs/`; файлы здесь — собранные артефакты
(редакция ноябрь 2026, продукт v1.0.0).

| Файл | Аудитория | Назначение |
|---|---|---|
| `Партнёр_Инструкция_для_непрограммиста.docx/.pdf` | директор, разработчик, юрист | первый запуск и повседневная работа без программиста |
| `Партнёр_Руководство_по_настройке_и_использованию.docx/.pdf` | администратор, директор | установка Docker Compose, CLI, эксплуатация |
| `Партнёр_Лицензирование_Инструкция_суперадминистратора.docx/.pdf` | суперадминистратор вендора | выдача и сверка лицензионных ключей |
| `Партнёр_Суперадминистратор_Расширенная_инструкция.docx/.pdf` | суперадминистратор вендора | полный цикл лицензий, релизов и поддержки |
| `Партнёр_Шпаргалка_A4.docx` | все роли | одна страница ключевых команд и цифр |

## Правила обновления

- При изменении кода, затрагивающем команды, установку или лицензирование,
  обновите соответствующий markdown-источник и пересоберите артефакты.
- PDF и DOCX не редактируются в git вручную: правки вносятся в источник,
  затем файлы заменяются целиком.
- Вендорские инструкции суперадминистратора не входят в клиентскую
  поставку (ADR-0018).
