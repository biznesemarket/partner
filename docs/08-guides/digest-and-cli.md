## 1. Утро разработчика (дайджест)

```text
Доброе утро, Иван. Итог дня 2026-11-12 (проект «Партнер»):

За день:   6,6 оплач. ч  →  3 300 ₽  →  0,0330%
  активное время  4,0 ч · супервизия 2,0 ч · автономное 0,6 ч (из 3,0 ч, кап 2,0)
Накоплено: 97 200 ₽  →  0,9720%
Вестинг:   активный месяц 4 из 20 ч (прогресс 20%)
Пул:       использовано 9,7% (ok)
Капы/флаги: autonomous_cap_applied
Ближайшая веха: 1,0% к 2026-12-20 при текущем темпе

Спор по дню — до 2026-11-15: partner dispute 2026-11-12
```

Правила текста: сначала деньги и доля, потом расшифровка; каждый флаг
объясняется одной строкой; спор и его срок всегда указаны.

## 3. CLI-команды

| Команда | Кто | Что делает |
|---|---|---|
| `partner status` | участник | текущая сессия, сегодняшний час и начисление |
| `partner day [date]` | участник | итог дня: часы по классам, ₽ и %, капы, флаги |
| `partner explain date` | участник/директор | раскладка по интервалам: класс, коэффициент, ставка, капы |
| `partner snapshot YYYY-MM` | все | месячный итог + SHA-256, прогресс вестинга |
| `partner dispute date` | участник | открыть спор по дню |
| `partner digest day|month key --participant id` | участник/директор | дайджест из БД сервера (M6) |
| `partner snapshot-close YYYY-MM --by …` | директор | закрепить месячный снапшот долей: sha256 + git-якорь (M7) |
| `partner legal-gates` / `legal-gate` / `legal-enable` | юрист | отчет, снятие гейтов G-01…G-08, включение модуля (M7) |
| `partner policy set rate 600 --reason "..."` | директор | новая версия ставки |
| `partner init` | директор | мастер настройки (см. onboarding-wizard.md) |
| `partner export-legal --to lawyer/` | юрист | пакет юристу (06-legal §7): политика, снапшоты, гейты, вопросы, шаблоны |

## 4. Принципы витрины

- Никакого дашборда в MVP (ADR-0018): дайджест — основная поверхность,
  CLI — детализация.
- Любая цифра объясняется: `explain` показывает все коэффициенты и капы
  конкретного дня.
- Дайджест не содержит данных других участников (кроме сводки директора
  без содержимого работы).
