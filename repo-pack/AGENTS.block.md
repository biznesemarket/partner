# Правила учета «Партнер» (обязательны для ИИ-агента)

Этот блок читается агентом первым. Время вашей работы с агентом
учитывается и конвертируется в вознаграждение и долю по правилам
`policy.yaml` в корне этого репозитория.

## Обязательные правила для агента

1. **Привязка сессии к задаче.** Каждая сессия работы с агентом должна
   ссылаться на задачу (issue) и ветку. Сессия без привязки учитывается,
   но не оплачивается (`no_task_link`).
2. **Не «разогревать» агента впустую.** Время классифицируется:
   - активное время человека (ввод, правки, навигация) — 100% ставки;
   - супервизия (агент работает, вы подтверждаете шаги) — коэффициент
     `k_supervised`;
   - автономная работа (агент работает, человека нет) — коэффициент
     `k_autonomous` (по умолчанию 0,2) и не более 2,0 оплачиваемых
     часов в сутки;
   - простой (нет активности дольше 5 минут) — 0%, сессия на паузе.
3. **Дневной кап.** Оплачивается не более `daily_cap_hours` часов в сутки
   (по умолчанию 12). Параллельные сессии не суммируются.
4. **Честность.** Не имитируйте активность (макросы, автокликеры),
   не replay-ите события: дни с флагами `synthetic_input` / `replay`
   проверяются директором; `replay` отменяет начисление.
5. **Маркировка коммитов агента.** Trailer `Co-authored-by: <agent> <agent@…>`,
   метка `agent` в PR и подтверждение человека-владельца.
6. **Данные.** Не отправляйте код и данные клиента во внешние модели
   без разрешения; телеметрия учета не содержит содержимого файлов.

## Ключевые параметры проекта (из policy.yaml)

| Параметр | Значение |
|---|---|
| Оценка проекта | 10 000 000 ₽ |
| Ставка часа с ИИ-агентом | 500 ₽/ч (версионируется) |
| Дневной кап | 12 ч |
| Коэффициент автономного времени | 0,2 |
| Пул участников | 30% |
| Закрытие дня | 00:00 Europe/Moscow |

## Отчеты

```text
partner status              # текущая сессия
partner day                 # итог вчерашнего дня
partner explain <date>      # раскладка расчета
partner snapshot <YYYY-MM>  # месячный итог
```

День закрывается автоматически в 00:00; спор — в течение 3 суток.
Изменение ставки/оценки действует с даты, задним числом — никогда.
