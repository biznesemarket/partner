# VS Code-плагин «Партнер»

Тонкая обертка над `partner-agent` (agent-kit): кнопки «начать/завершить
сессию», статус-бар и heartbeat каждые 30 секунд.

## Установка

1. Установите пакет: `pip install partner-tracker` (или `pip install -e .`).
2. Проверьте, что `partner-agent init` создал `~/.config/partner/agent.yaml`.
3. Скопируйте каталог `apps/partner_agent_kit/vscode` в
   `~/.vscode/extensions/partner-agent-vscode-1.1.0` или упакуйте через
   `vsce package`.
4. Перезапустите VS Code. В статус-баре появится «Партнер».

## Что уходит на сервер

Только счетчики: события ввода, фокус, вызовы инструментов, число
затронутых файлов. Текст документов, промпты, код и имена файлов не
передаются. Офлайн-события буферизуются на диск и отправляются позже.
